# Explainable Machine Learning Analysis of AVF Use in Hemodialysis Patients

This repository contains the Python code used for the study:

**“Explainable Machine Learning Characterization of Routine Clinical Variables Associated with Arteriovenous Fistula Use in Hemodialysis Patients”**


## About the Study

This study uses machine-learning methods to examine clinical factors associated with arteriovenous fistula (AVF) use in patients receiving maintenance hemodialysis.

Routine demographic, clinical, and laboratory variables were included in the analysis. Machine-learning models were developed and evaluated, and explainable machine-learning methods were used to better understand how individual clinical variables contributed to model predictions.

## Repository Contents

The code in this repository covers the main steps of the analysis, including:

- Data preparation and preprocessing
- Model training and validation
- ROC curve and AUC analysis
- Model performance evaluation
- Calibration analysis
- Feature importance analysis
- SHAP analysis
- Decision curve analysis
- Generation of figures used in the study

## Data Availability

The original patient-level dataset is not included in this repository because the clinical data are subject to privacy, ethical, and data-use restrictions.

The code is provided to make the analytical workflow of the study transparent and to support reproducibility. Researchers wishing to reproduce the analysis will need to prepare their data in a structure consistent with the variables used in the study.

Please refer to the Data Availability Statement in the manuscript for additional information about access to the study data.

## Requirements

- XGBoost
